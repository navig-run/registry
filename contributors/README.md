# Contributors

Contributor profiles for the NAVIG registry. Each profile is a YAML file named
after your handle — e.g. `contributors/octocat.yaml`.

This directory currently has no profiles: the registry's initial content was
authored by the NAVIG core team, and we don't create placeholder or synthetic
profiles. The first community contribution to merge starts this list.

## How to get listed

1. Contribute something real first — a CLI skill, AI skill, space, persona,
   library template, or a meaningful fix. See [CONTRIBUTING.md](../CONTRIBUTING.md).
2. In the same PR (or after it merges), copy the template:

   ```bash
   cp _template.yaml contributors/<your-handle>.yaml
   ```

3. Fill in your details. Link the contribution(s) you made — profiles must
   reference at least one merged contribution in this repository.
4. Open the PR. Profiles are reviewed alongside the contribution they cite.

## Rules

- One profile per person, named after your GitHub handle.
- Only real people with merged contributions — no placeholder, brand, or
  synthetic profiles.
- Keep it to the fields in [`_template.yaml`](../_template.yaml); no tracking links or ads.

Notable contributions are additionally curated in [SHOWCASE.md](../SHOWCASE.md).
