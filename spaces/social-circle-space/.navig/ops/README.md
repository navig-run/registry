# Social Circle Space — Ops

## Add a New Contact
1. Drop contact info to `#contacts` inbox
2. Agent suggests circles and tags based on context
3. Review and confirm placement
4. Log first interaction

## Log an Interaction
1. Post to `#interactions`: who, when, what
2. Agent updates lastContact timestamp
3. Follow-up notes stored on contact record

## Respond to a Warmth Alert
1. `#warmth` shows contacts going cold
2. Review who and when last contacted
3. Reach out (note: this space doesn't send messages, you do)
4. Log the interaction after

## Import Contacts
1. Export CSV or vCard from source
2. Drop in inbox
3. Agent deduplicates and suggests circle placement
4. Review and confirm

## Formation Quick-Start
- **Weekly**: Review `#warmth` alerts
- **Monthly**: Full circle review — who moved in/out?
