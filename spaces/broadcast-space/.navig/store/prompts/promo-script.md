# Promo Script

## Purpose
Create promotional scripts for upcoming episodes across different platforms.

## Variables
- `{{EPISODE_TITLE}}` — Episode title
- `{{EPISODE_NUMBER}}` — Episode number
- `{{GUEST_NAME}}` — Guest name (if applicable)
- `{{KEY_INSIGHT}}` — Most compelling insight from the episode
- `{{PUBLISH_DATE}}` — Episode release date
- `{{SHOW_NAME}}` — Podcast name

## Prompt

Create promotional scripts for **Episode {{EPISODE_NUMBER}}: {{EPISODE_TITLE}}** of **{{SHOW_NAME}}**.

**Guest**: {{GUEST_NAME}}
**Key Insight**: {{KEY_INSIGHT}}
**Release Date**: {{PUBLISH_DATE}}

### 1. Teaser Clip Script (15 seconds)
- Voiceover text for a pre-release teaser
- Build curiosity without giving away the full insight

### 2. Social Media Captions

**Twitter/X** (280 chars max):
- Hook + key insight + CTA + link

**Instagram** (2200 chars max):
- Opening hook
- 3 bullet points of what they'll learn
- CTA to listen
- Relevant hashtags (5-10)

**LinkedIn** (3000 chars max):
- Professional angle on the topic
- Key takeaway for professionals
- CTA to listen

**TikTok/Reels** caption (150 chars):
- Punchy hook for video clip

### 3. Email Newsletter Blurb
- Subject line (50 chars max)
- 2-paragraph teaser
- CTA button text

### 4. In-Episode Promo (for cross-promotion)
- 30-second script to read on other episodes
- Conversational tone, not salesy

### 5. Audiogram Text Overlay
- 3-5 short text lines for audiogram video
- Each line max 8 words
