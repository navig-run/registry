# Sponsor Read

## Purpose
Generate natural-sounding sponsor ad reads that fit the show's tone.

## Variables
- `{{SPONSOR_NAME}}` — Sponsor/brand name
- `{{PRODUCT}}` — Product or service being promoted
- `{{KEY_BENEFIT}}` — Main benefit to highlight
- `{{PROMO_CODE}}` — Discount code (if applicable)
- `{{URL}}` — Sponsor URL
- `{{DURATION}}` — Read duration (15s, 30s, 60s)
- `{{TONE}}` — Show tone (casual, professional, humorous)

## Prompt

Write a sponsor read for **{{SPONSOR_NAME}}** ({{PRODUCT}}).

**Key Benefit**: {{KEY_BENEFIT}}
**Promo Code**: {{PROMO_CODE}}
**URL**: {{URL}}
**Duration**: {{DURATION}}
**Tone**: {{TONE}}

### Pre-Roll Read ({{DURATION}})
Natural transition from intro into sponsor message. Should feel like a personal recommendation, not a commercial.

### Mid-Roll Read ({{DURATION}})
Transition from content → sponsor → back to content. Include a personal anecdote or use case if possible.

### Post-Roll Read (15s)
Quick reminder with URL and promo code.

### Guidelines
- Sound authentic — use "I" and personal experience
- Mention the product name 2x (beginning and end)
- Include the URL and promo code clearly
- Natural transition phrases (not "and now a word from...")
- CTA: what should the listener do right now?
