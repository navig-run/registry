# Forge Space — Agent Guide

> These roles are the **design target**. No agent files ship with this space yet
> (`.navig/space.json` lists none); see `.navig/GENESIS.md`.

## dream-compiler
Transforms plain-English capability descriptions into scaffolded pack structures. Entry point for all new capability development.

## pack-tester
Runs packs in isolation to validate behavior before publishing.

## pack-publisher
Handles versioning, packaging, and publication to the community store.
