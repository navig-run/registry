# Forge Space — Ops

## Build a New Pack

1. Drop capability description into `#ideas`
2. Dream compiler generates scaffold
3. Iterate on implementation
4. Test in isolation
5. Package and version
6. Publish to community store

## Pack Quality Gates

Before shipping:
- [ ] Manifest complete (name, version, description, capability_deps)
- [ ] Tests passing
- [ ] README explains what it does and how to install
- [ ] No hardcoded paths or credentials
