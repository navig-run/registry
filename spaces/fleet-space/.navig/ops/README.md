# Fleet Space — Ops

## Launch a Fleet Mission

1. Define the master task in `#missions` inbox
2. Fleet commander decomposes into N sub-tasks
3. Spawn N agents, assign sub-tasks
4. Monitor progress via `#status`
5. Commander integrates results when all agents complete
6. Final output posted to `#results`

## Conflict Resolution

When agents produce contradictory outputs, the fleet commander:
1. Identifies the conflict
2. Synthesizes the strongest elements from each
3. Notes unresolved conflicts in the output
