# Travel Space — Wiki

## What This Space Does

Plans, tracks, and archives every trip. From rough idea to post-trip debrief,
all trip logistics, documents, and memories live here.

## Quick Reference

| Agent | Inbox | What It Does |
|-------|-------|-------------|
| trip-planner | #trip-ideas | Creates trips, estimates, overall status |
| itinerary-builder | #active-trip | Day-by-day planning and activity management |
| budget-watcher | #bookings | Tracks bookings vs budget, flags overruns |
| document-keeper | #documents | Documents, checklist, passport/visa tracking |

| Workflow | When |
|----------|------|
| new-trip | When you commit to a destination |
| pre-departure | 24–48 hours before travel |
| trip-debrief | Within 48 hours of returning |

## Folder Per Trip

Every trip lives in `trips/{slug}/` with a consistent structure:
- `trip.json` — metadata and status
- `itinerary.md` — day-by-day plan
- `budget.json` — cost tracking
- `bookings/` — confirmation PDFs
- `documents/` — visa, insurance, etc.
- `notes/` — research, on-trip notes
- `debrief.md` — written after returning
