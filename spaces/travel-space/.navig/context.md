# Travel Space — Context

## Domain

Personal travel — planning, budgeting, packing, documenting, debriefing.
Every activity in this space belongs to a named trip.

## Status Model

A trip moves through: `idea → planned → booked → active → completed → archived`

## What Lives Here

- Trip definitions and status
- Day-by-day itineraries
- Booking confirmations (local copies)
- Travel budgets (estimated vs actual)
- Document copies (for offline access when traveling)
- Post-trip notes and debriefs

## Principles

1. No trip should have an unknown total cost commitment after all bookings are made.
2. Documents are organized per trip — never loose files.
3. Debrief within 48 hours or it doesn't happen.
4. Packing list is maintained per trip — starts from the personal master template.

## Boundaries

- Business expense reimbursement → finance-space
- Pure work conferences (no leisure) → work formations
- Visa applications requiring legal help → delegate to external specialist
