# Learn Space — Ops

## Daily Learning Protocol

1. During session: capture insights in real time to #insights
2. After session: update progress (pages read, modules completed) in course/book file
3. Tag insights with source item and skill area

## Weekly Review Protocol (every Sunday)

1. Open review-scheduler: surface all items due for spaced repetition
2. Quiz yourself on each item — update confidence score
3. Review progress on all active learning items
4. Identify anything stale (no progress in 14+ days) — continue, pause, or abandon
5. Log the review: reviews/{YYYY-WW}.md

## Completion Protocol

1. Mark item complete in library file
2. Write final summary: key insights, skill impact, recommendation
3. Create at least 3 quiz cards for the most important insights
4. Update skill profile for all related skills

## Abandonment Protocol

1. Log reason in library file
2. Capture any insights gathered before abandoning
3. Mark as abandoned (not deleted — may resume later)

## Insight Staleness Alert

Insights not reviewed in 45+ days are surfaced by review-scheduler.
At 90 days, an insight with no reviews is flagged for removal or re-capture.
