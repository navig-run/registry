# Learn Space — Wiki

## What This Space Does

Tracks courses and books, captures insights, manages spaced repetition,
and maps all learning to skill development.

## Quick Reference

| Agent | Inbox | What It Does |
|-------|-------|-------------|
| course-tracker | #courses | Library management, progress tracking |
| book-synthesizer | #insights | Insight capture, summaries, quiz cards |
| skill-planner | #skills | Skill profiles, gap analysis, learning paths |
| review-scheduler | #reviews | Spaced repetition queue and weekly review |

| Workflow | When |
|----------|------|
| start-course | Adding any new learning item |
| weekly-review | Every Sunday |
| skill-assessment | Quarterly |

## The Learning Loop

1. **Add item** → start-course workflow
2. **Learn** → capture insights to #insights as you go
3. **Review** → weekly-review every Sunday
4. **Assess** → skill-assessment quarterly

## Key Metrics to Watch

- Finish rate (target ≥70%)
- Weekly review streak
- Insights per completed item (target ≥3)
- Skills at proficient or above
