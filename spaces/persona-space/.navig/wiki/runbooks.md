# Persona Space — Runbooks

## Create Your First Persona

1. Answer 5 questions in `#design`:
   - How do you want your agent to sound?
   - What reasoning style do you prefer?
   - What are your 3 most important decision heuristics?
   - What domains should it know deeply?
   - What tendencies should it compensate for?
2. Persona designer structures the responses
3. Review and adjust
4. Save as v0.1
5. Run a test session with the persona active

## Publish to Gallery

1. Review persona for anything private
2. Add a tagline: "My agent sounds like X, thinks like Y"
3. Post to `#gallery` inbox
4. Community can fork it
