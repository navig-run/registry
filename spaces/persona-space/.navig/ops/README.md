# Persona Space — Ops

## Design a New Persona

1. Drop design notes in `#design` inbox
2. Persona designer agent structures them into sections
3. Review and refine each component
4. Save as versioned persona (v0.1, v0.2...)
5. Optionally publish to persona gallery

## Diff Two Versions

1. Select v(n) and v(n-1) from version history
2. Persona differs generates a summary of what changed
3. Review: intentional vs drift

## Fork a Community Persona

1. Browse persona gallery
2. Fork a persona that resonates
3. Adapt sections to match your style
4. Save as your v0.1
