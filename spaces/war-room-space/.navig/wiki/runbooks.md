# War Room Space — Runbooks

## Weekly War Room Brief

**Formation:** `intel-sweep`  
**Frequency:** Weekly

### Steps
1. Pull all intel logged since last brief
2. Rate each item: severity + confidence
3. Summarize top threats by theater
4. strategist reviews and sets priorities
5. Update `memory/operations.json` if any new ops initiated

---

## Incident Response Activation

**Trigger:** Severity 8+ intelligence event or active attack

### Steps
1. Activate `spaces/incident/` sub-space
2. Full `ops-command` formation briefing
3. Assign theater leads and resources
4. Define objective and success criteria
5. Run daily status check until resolved
6. Close incident with debrief and archive

---

## Arsenal Audit

**Trigger:** Quarterly

### Steps
1. Review each arsenal category
2. Update/deprecate outdated assets
3. Identify gaps against current threat model
4. Add new assets as needed
