# War Room Space — Ops

## Ops Procedures

### Activate Incident Response
1. Open incident sub-space at `spaces/incident/`
2. Activate `ops-command` formation
3. Brief all agents on situation
4. Assign theater leads

### Intelligence Sweep
1. Activate `intel-sweep` formation
2. intelligence-officer pulls all recent signals
3. Rate each: severity (1-10), confidence (1-10)
4. Log in `memory/intel-log.json`
5. Escalate anything severity >7

### Narrative Response
1. `#narrative` inbox receives an attack
2. narrative-engineer assesses the attack vector
3. Draft counter-narrative + supporting messaging
4. strategist approves and deploys

## Formation Quick-Start
- **Daily**: Monitor `#intel` inbox
- **Weekly**: `intel-sweep` formation
- **On incident**: `ops-command` + sub-space activation
