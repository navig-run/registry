# Caption Prompt

## Purpose

Generate platform-optimised captions and descriptions for short-form clips.

## Variables

- `{{TOPIC}}` — Clip topic
- `{{PLATFORM}}` — Target platform
- `{{TONE}}` — Tone: casual, expert, funny, dramatic, inspirational
- `{{CTA}}` — Desired call to action

## Prompt

You are writing captions for a short-form video clip.

**Topic**: {{TOPIC}}
**Platform**: {{PLATFORM}}
**Tone**: {{TONE}}
**CTA**: {{CTA}}

### Requirements

- TikTok: 150 chars max, emoji-heavy, trend-aware language
- Reels: 2200 chars max, first line = hook, hashtags at end
- Shorts: 100 chars max, direct and searchable

### Generate

**TikTok Caption**:
(hook line + CTA + 3-5 hashtags)

**Reels Caption**:
(hook paragraph + value + CTA + 10-15 hashtags)

**Shorts Title**:
(searchable, keyword-rich, under 100 chars)
