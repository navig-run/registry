# Hook Framework

> Formulas and techniques for scroll-stopping first 3 seconds.

## Why Hooks Matter

- Average scroll-past time: 0.3 seconds
- 3-second retention is the #1 algorithm signal
- A great hook can 10x views on the same content

## Hook Types

### 1. Curiosity Gap
Create an open loop the viewer must close.

- "You've been doing X wrong your entire life"
- "The real reason why X happens"
- "Nobody talks about this but..."

### 2. Bold Statement
Make a claim that demands attention.

- "This one trick saved me 4 hours a day"
- "Stop doing X immediately"
- "X is dead. Here's what to do instead"

### 3. Question Hook
Ask something the viewer wants answered.

- "Want to know how I X?"
- "Why does nobody do this?"
- "What if you could X in 30 seconds?"

### 4. Pattern Interrupt
Break the expected visual pattern.

- Unexpected visual (zoom, cut, prop)
- Contrasting text on screen
- Sound effect or silence break
- Physical movement or gesture

### 5. Shock/Contrast
Show before/after, expectation vs reality.

- "I tried X for 30 days. Here's what happened"
- Split screen before/after
- "Everyone says X. But actually..."

### 6. Direct Address
Speak directly to a specific person.

- "If you're a [specific role], watch this"
- "This is for the people who..."
- "POV: You just discovered..."

## Hook Formula Templates

```
1. [Number] + [Benefit] + [Timeframe]
   → "5 tools that saved me 10 hours this week"

2. [Contrarian] + [Reality]
   → "Stop waking up at 5am. Here's what actually works"

3. [Qualifier] + [Promise]
   → "If you're a developer, this will change everything"

4. [Action] + [Surprising result]
   → "I deleted all my apps. Watch what happened"
```

## Hook Don'ts

- Never bury the hook after second 3
- Never start with "Hey guys" or "Welcome back"
- Never use hooks that don't match the content (clickbait backfires)
- Never use the same hook structure repeatedly

## Testing Hooks

1. Write 3 variants per clip
2. Score each with hook-score skill
3. A/B test top 2 on different platforms
4. Track 3-second retention rate per hook type
5. Build a "proven hooks" library from winners
