# Brand Template

Copy all files in this directory to `brands/{slug}/` to set up a new brand.

## Quick Start

```bash
# Copy
cp -r brands/_template brands/my-brand

# Edit these 3 files:
#   brands/my-brand/voice.json       — personality, tone, rules
#   brands/my-brand/accounts.json    — social media accounts
#   brands/my-brand/guidelines.md    — narrative brand guide

# Then follow docs/BRAND_SETUP.md — Activation Checklist
```
