# Scripts

Utility scripts for local operations, CI helper tasks, and one-off automation.

## Usage Convention

All scripts must:
1. Accept `--help` / `-h` and print usage
2. Exit non-zero on failure
3. Include a header comment with: purpose, prerequisites, author
