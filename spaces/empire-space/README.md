# Empire Space

> Portfolio command center for multi-venture operators. Every company tracked, every revenue stream visible, every decision logged.

## Agents

| Agent | Role |
|-------|------|
| `portfolio-commander` | Portfolio overview, priorities, venture health |
| `venture-scout` | Pipeline evaluation, stage advancement |
| `revenue-tracker` | Revenue streams, MRR, ARR, trends |
| `market-analyst` | Signals, competitor intel, opportunity flagging |

## Skills

| Skill | Purpose |
|-------|---------|
| `advance-stage` | Advance venture through idea → validation → growth → scaling → exit |
| `log-decision` | Append-only strategic decision record |
| `track-revenue` | Log or update revenue stream |
| `channel-audit` | Channel performance breakdown with concentration risk |

## Stage Pipeline

```
idea → validation → growth → scaling → exit | archived
```

## Workflows

| Workflow | Schedule | Purpose |
|----------|---------|---------|
| `weekly-portfolio-review` | Mon 08:00 | Venture health, revenue trend, open signals |
| `monthly-empire-review` | 1st of month | Full P&L, stage audit, channel analysis |
