# Empire Space — Ops

This directory contains operational runbooks and procedures for Empire Space.

## Ops Procedures

### Start a Portfolio Review
1. Activate `portfolio-ops` formation
2. Review each venture's status in `ventures/`
3. Check revenue tracker summary
4. Log any strategic decisions

### Add a New Venture
1. Create venture profile in `ventures/`
2. Register revenue streams
3. Brief portfolio-commander on key metrics

### Market Signal Response
1. New signal arrives in `#signals` inbox
2. market-analyst rates and summarizes
3. portfolio-commander decides on action

## Formation Quick-Start
- **Daily**: No specific formation — check status via inbox
- **Weekly**: `portfolio-ops` formation for venture status review
- **Monthly**: Full `venture-review` formation cycle
