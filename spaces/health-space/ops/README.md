## Weekly Check-In

```
[ ] Review metrics (weight, HRV, sleep avg, mood)
[ ] Update .navig/memory/ with any significant changes
[ ] Flag items for doctor/specialist review → inbox/
[ ] Process any inbox/ items from the week
```

---

## Lab / Appointment Prep

1. Export any relevant metrics to `out/`
2. Prepare question list in `inbox/` before the appointment
3. Post-appointment: store results in `out/`, notes in `docs/`
