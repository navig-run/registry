# Deployment Nerve Center

> Every deploy. Every diff. Every rollback. One view.

**Tier:** platform · **Status:** planned  
**Owner:** navig-run · **Created:** 2026-03-17

---

## Purpose

Deployments are high-stakes moments that happen too fast to track manually.
This space aggregates deploy history, diffs, environment states, and rollback
triggers into a single view — so you always know what changed, when, and what
to do if it breaks.

---

## What lives here

- Deploy history logs
- Diff archives (per deploy)
- Environment state snapshots
- Rollback runbooks
