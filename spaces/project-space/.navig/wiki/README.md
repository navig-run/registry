# Project Space — Wiki

## What This Space Does

Manages personal projects from idea to done. Keeps scope clear, progress
visible, and blockers resolved.

## Quick Reference

| Agent | Inbox | What It Does |
|-------|-------|-------------|
| project-planner | #projects | Project scope, kickoff, status, close |
| task-tracker | #tasks | Individual tasks — add, update, complete |
| milestone-keeper | #milestones | Milestone progress and slip tracking |
| blocker-resolver | #blockers | Blocker log, next actions, escalation |

| Workflow | When |
|----------|------|
| new-project | Any new project |
| weekly-standup | Every Monday — all active projects |
| project-close | When done-state is met |

## The Project Lifecycle

```
IDEA → ACTIVE → (PAUSED) → DONE → ARCHIVED
```

Every state transition must be explicit.
A project cannot be "done" without a written close.md.

## The Three Rules

1. No project without a done-state.
2. No blocker without a next action within 24 hours.
3. No project stale for 14+ days without a status update.
