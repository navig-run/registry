# Project Space — Ops

## New Project Protocol

1. Name the project (clear, noun-based: "Home Office Setup", not "office stuff")
2. Write the done-state: exactly what does done look like?
3. Set milestones: 3–7 named checkpoints
4. Identify first 3 tasks
5. Identify any known dependencies or blockers up front

## Weekly Standup Protocol (every Monday)

For each active project:
1. What was completed since last standup?
2. What's the next milestone status?
3. Are there any blockers? If yes → log to blockers.md immediately
4. What are the 1–3 priority tasks this week?

Total time: < 10 minutes for all projects

## Blocker Protocol

When a blocker is identified:
1. Log immediately to blockers.md: description, date logged, blocking what
2. Assign a next action within 24 hours
3. If unresolved after 3 days → escalate to #blockers channel

## Project Pause Protocol

A project can be paused (not abandoned). Pause requires:
- Reason for pause
- Resume date (or condition)
- Current state documented

## Project Close Protocol

1. Verify done-state is met
2. Write close.md: what was built, what worked, what didn't, what was learned
3. Archive all project files to projects/archived/{slug}/
4. Update known-issues.json if applicable
