# GENESIS — Studio Space

## Why This Exists

Music production is inherently multi-stage: composition, recording, mixing, mastering, release. Each stage has its own tools, standards, and failure modes. Without a central command layer, projects stall in forgotten session folders, mixes never get final QC, and releases launch with metadata errors.

Studio Space provides a single orchestration layer across the entire production lifecycle.

## What It Does

- **Session management** — track every DAW project, plugin chain, and bounce across sessions
- **Mix engineering** — loudness metering, frequency analysis, stem management, reference comparison
- **Mastering pipeline** — LUFS compliance, format conversion, final QC checklists
- **Release ops** — metadata tagging, distributor upload prep, platform-specific format export
- **Sample library** — catalog, tag, search, and deduplicate samples and presets
- **Collaboration** — session prep, stems export, project packaging for collaborators

## Core Agents

| Agent | Role |
|-------|------|
| `producer` | Creative direction, arrangement, session orchestration |
| `mix-engineer` | Level balancing, EQ, compression, spatial placement |
| `sound-designer` | Sample creation, synthesis, sound palette curation |
| `release-manager` | Distribution, metadata, platform compliance |
| `session-planner` | Calendar, deadlines, session prep, asset tracking |

## Primary Formations

- **`track-production`** — End-to-end single track production pipeline
- **`release-pipeline`** — From final master to live on all platforms
- **`sample-lab`** — Sample discovery, processing, and cataloging
- **`mastering-suite`** — Final mix QC and master delivery
- **`collab-session`** — Multi-artist session coordination

## Origin

Built for independent producers, beatmakers, and audio engineers who want their production workflow as organized as their sound.
