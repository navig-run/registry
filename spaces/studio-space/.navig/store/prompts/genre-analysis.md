# Genre Analysis

## Purpose

Analyse a genre or subgenre to extract production conventions, sonic characteristics, and arrangement patterns. Useful when starting work in an unfamiliar style.

## Variables

- `{{GENRE}}` — Genre or subgenre to analyse
- `{{REFERENCE_TRACKS}}` — 3–5 representative tracks (artist — title)
- `{{ERA}}` — Time period focus (e.g., "2020s", "classic", "all")
