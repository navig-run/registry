# Space: studio

## Purpose
Music production command center spanning the entire lifecycle — composition, recording,
mixing, mastering, sample management, and release distribution. Works with any DAW on
Windows, Linux, and macOS.

## Scope
- DAW sessions: Ableton, FL Studio, Logic, Reaper, Bitwig, Pro Tools
- Audio formats: WAV, FLAC, MP3, AAC, OGG, AIFF
- Standards: LUFS metering (streaming/broadcast/club), true peak, sample rates
- Distribution: Spotify, Apple Music, YouTube Music, Bandcamp, SoundCloud
- Collaboration: stem exchange, session packaging, version control

## Active Agents
producer · mix-engineer · sound-designer · release-manager · session-planner

## Active Formations
track-production · release-pipeline · sample-lab · mastering-suite · collab-session
