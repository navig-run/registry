# Genre Palette

> Quick-reference guide to production conventions across popular genres.

## Electronic

### House
| Attribute | Convention |
|-----------|-----------|
| BPM | 120–130 |
| Key | Am, Cm, Gm common |
| Drums | Four-on-the-floor kick, open hi-hats on off-beats |
| Bass | Side-chained to kick, often synth |
| Structure | 32-bar intro, builds, drops | 

### Techno
| Attribute | Convention |
|-----------|-----------|
| BPM | 128–140 |
| Key | Often atonal or minor |
| Drums | Minimal, mechanical, heavy reverb on claps |
| Bass | Driving, repetitive, acid lines common |
| Structure | Long intros/outros for DJ mixing |

### Drum & Bass
| Attribute | Convention |
|-----------|-----------|
| BPM | 170–180 |
| Key | Minor keys dominant |
| Drums | Breakbeats, Amen-style chops, heavy sub |
| Bass | Sub + mid-range reese or neuro |
| Structure | 16-bar intro, drop-heavy |

## Hip-Hop / R&B

### Trap
| Attribute | Convention |
|-----------|-----------|
| BPM | 130–170 (half-time feel at 65–85) |
| Key | Minor, often Am, Cm |
| Drums | 808 sub-bass, rapid hi-hats, snare on 3 |
| Melody | Dark pads, plucks, vocal chops |
| Structure | Hook-heavy, short verses |

### Boom Bap
| Attribute | Convention |
|-----------|-----------|
| BPM | 85–100 |
| Key | Varies, soul/jazz samples |
| Drums | Punchy kick/snare, vinyl crackle |
| Bass | Sampled or Moog-style |
| Structure | 16-bar verses, 8-bar hooks |

## Pop / Rock

### Pop
| Attribute | Convention |
|-----------|-----------|
| BPM | 100–130 |
| Key | Major keys (C, G, D) common |
| Drums | Punchy, compressed, often layered electronic + acoustic |
| Structure | Verse–prechorus–chorus, bridge before final chorus |
| Loudness | -10 to -14 LUFS |

### Rock
| Attribute | Convention |
|-----------|-----------|
| BPM | 110–140 |
| Key | E, A, D (guitar-friendly) |
| Drums | Live kit, room mics important |
| Guitar | Doubled hard-panned rhythm, centered lead |
| Structure | Intro–verse–chorus–verse–chorus–solo–chorus–outro |

## Ambient / Cinematic

| Attribute | Convention |
|-----------|-----------|
| BPM | 60–90 or free-tempo |
| Key | Modal, often Dorian or Mixolydian |
| Texture | Pads, granular synthesis, field recordings |
| Dynamics | Wide dynamic range (LRA 12–20 LU) |
| Loudness | -18 to -23 LUFS |

## Using This Reference

1. Pick the genre closest to your target
2. Use the BPM/key as a starting point (not a rule)
3. Run the `genre-analysis` prompt for deeper research
4. Cross-reference with current chart releases
