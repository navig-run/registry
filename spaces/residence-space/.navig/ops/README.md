# Residence Space — Ops

## Ops Procedures

### Weekly Home Review
1. Activate `household-ops` formation
2. Walk through each room mentally (or physically)
3. Log anything needing maintenance, repair, or restocking
4. Update inventory for consumed/expired items
5. Check medication expiry dates

### Maintenance Task
1. Log task in `#maintenance` inbox
2. steward assesses: urgency, cost, DIY vs service
3. Schedule task in maintenance log
4. Complete and close with notes

### Medication Expiry Check
1. medic reviews `.navig/memory/medication-log.json`
2. Flag items expiring within 30 days
3. Log refill needs
4. Update record after refill

## Formation Quick-Start
- **Weekly**: `household-ops` for home review
- **Monthly**: `maintenance-crew` for scheduled maintenance
- **As needed**: `medical-watch` for medication management
