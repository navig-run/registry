# Projects Ops

Project delivery runbooks and checklists.

---

## Project Kickoff Checklist

```
[ ] Define scope and outcome in docs/<project>/spec.md
[ ] Identify stakeholders and decision makers
[ ] Set milestone plan in .navig/plans/
[ ] Create inbox/ folder entry for the project
[ ] Assign responsible owner
```

---

## Delivery Checklist

```
[ ] All milestones marked complete in .navig/plans/
[ ] Deliverables reviewed and approved
[ ] Outputs moved to out/<project>/
[ ] ADR written if any significant decisions were made
[ ] Stakeholders notified
[ ] Post-project note written (what worked, what didn't)
```

---

## Sprint Review (Weekly)

```
[ ] Update milestone status in .navig/plans/
[ ] Move completed items from inbox/ to out/
[ ] Identify blockers — flag in ops/ or escalate
[ ] Update .navig/memory/ if project context has changed
```
