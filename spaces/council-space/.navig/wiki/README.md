## Key Concepts

**Council**: A group of 3-9 agents each arguing from a defined perspective.

**Debate round**: Each agent presents their position; others may rebut.

**Decision card**: Final output — decision + rationale + confidence + dissents.

**Quorum**: 60% of agents must align for a decision to carry.
