# Council Space — Runbooks

## Run a Debate Session

**Trigger:** A decision needs multi-perspective analysis

### Steps
1. Write the question clearly in `#questions`
2. Select 3-7 agents from council roster
3. Assign moderator agent
4. Activate `council-debate` formation
5. Each agent presents position (1-3 paragraphs)
6. Rebuttal round: each agent responds to the strongest opposing argument
7. Moderator extracts decision card
8. Log to `#decisions` inbox

---

## Add a New Council Agent

1. Define the agent's perspective / bias / expertise
2. Create agent YAML in `.navig/store/agents/`
3. Test in a low-stakes session first
4. Document in agent-guide.md
