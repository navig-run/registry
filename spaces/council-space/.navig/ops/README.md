# Council Space — Ops

## Quick Start

1. Define your question in `#questions` inbox
2. Select 3-7 agents for the council
3. Run `council-debate` formation
4. Review decision card and dissents
5. Log decision to memory

## Council Agent Roster

Populate agents in `.navig/store/agents/` as you build your council library.

## Session Format

Each session produces:
- **Decision card**: statement, rationale, confidence
- **Dissent record**: minority views and the strongest counter-arguments
- **Metadata**: agents used, rounds, date
