# Radar Space — Runbooks

## Monthly Cost Review

**Frequency:** First week of month

1. Pull cost data for prior month
2. Compare to prior 3-month average
3. Identify services with >20% increase
4. For each anomaly: trace to root cause
5. Update budgets if spend has legitimately shifted
6. Publish monthly report card

## Alert Triage

1. Receive alert in `#alerts`
2. Check: which service, how much, vs baseline?
3. Investigate: what changed? (new feature, traffic spike, config error?)
4. Remediate or document as expected
5. Close alert with notes
