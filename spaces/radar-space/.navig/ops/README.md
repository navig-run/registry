# Radar Space — Ops

## Register a Service
1. Add service to service registry
2. Set expected monthly budget
3. Configure data source / API connection
4. Set anomaly threshold

## Respond to an Alert
1. Check `#alerts` inbox
2. Identify the spike source
3. Determine: expected vs unexpected
4. If unexpected: trace to root cause and remediate
5. If expected: adjust budget / suppress for N days

## Monthly Report
1. Pull cost summary for prior month
2. Compare to previous months
3. Identify top cost drivers
4. Post summary to `#reports` inbox
