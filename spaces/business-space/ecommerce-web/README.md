# E-commerce Web

Templates and SOPs for running an own-website selling channel (WooCommerce, Shopify, or custom).

## Quick Start

1. Choose your platform (Shopify / WooCommerce / custom)
2. Copy the product page template below and customise per SKU
3. Set up tracking: Google Analytics + Meta Pixel (or equivalent)
4. Connect payment gateway (Stripe recommended)

## Templates

| File | Purpose |
|------|---------|
| `product-page-brief.md` | Brief for writing/designing a product page |
