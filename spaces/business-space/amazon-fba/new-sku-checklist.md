# New FBA SKU Pre-Shipment Checklist

**SKU**: ___________________  
**ASIN**: ___________________  
**Shipment date**: ___________________

## Before Creating Shipment

- [ ] Listing is Active (not Suppressed or Inactive)
- [ ] All required images uploaded (min 6, including white background hero)
- [ ] Title, bullets, and description complete and approved
- [ ] Backend keywords populated (250 bytes)
- [ ] A+ Content submitted (if applicable)
- [ ] Price set and repricing rules configured
- [ ] Net margin ≥ 15% confirmed by finance-analyst
- [ ] Units to send calculated (safety stock formula applied)

## Shipment Creation Steps

- [ ] Create shipment in Seller Central
- [ ] Choose shipping method (small parcel / LTL)
- [ ] Label all boxes correctly (FNSKU labels on each unit)
- [ ] Box content lists uploaded
- [ ] Shipment tracking number added to Seller Central

## Post-Send

- [ ] Monitor shipment status in Seller Central
- [ ] Confirm units received and available for sale
- [ ] Activate PPC campaigns
- [ ] Record shipment in finance-ops/data/shipments.csv
