# GENESIS — Lab Space

## Why This Exists

The best way to learn NAVIG is to run things. Lab Space is the command REPL — a safe, stateful sandbox where you run commands, tweak them, see results, and share working sequences as shareable URLs.

Without it: experimentation is scattered and results are lost. With it: every experiment is captured, replayable, and shareable.

## What It Does

- **Live REPL** — run any NAVIG command with immediate feedback
- **Session history** — every command and result in a scrollable session log
- **Tweak mode** — modify a command and re-run to compare results
- **Share as URL** — export a working command sequence anyone can run in their NAVIG instance
- **Snippet library** — save useful command sequences for reuse

## Origin

Built for anyone who needs to try something before committing it to a workflow.
