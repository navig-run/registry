# Lab Space — Runbooks

## Save a Snippet

1. Run command sequence in REPL
2. Verify result is as expected
3. Select sequence and click "Save as Snippet"
4. Add description and tags
5. Optionally generate share URL

## Import a Shared Snippet

1. Receive share URL from another user
2. Open in lab-space
3. Review commands before running
4. Run in your NAVIG instance
5. Optionally save to your snippet library
