# Lab Space — Ops

## Start a Lab Session
1. Open lab-space
2. Run commands in the REPL
3. Tweaks are auto-saved to session log
4. Save useful sequences as snippets

## Share a Snippet
1. Select command sequence from session log
2. Click "Share" — generates URL
3. Recipient can run in their own NAVIG instance

## Snippet Library
All saved snippets stored in `.navig/memory/` and browsable via `#snippets` inbox.
