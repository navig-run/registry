# Personal Growth

Learning, habit formation, and self-improvement — courses, reading logs, skill targets, and reflection.

A standalone personal space (it pairs well with `human-space`). It holds the data and documents for intentional self-development: what you're learning, what you're building as a person, and the evidence that you're moving forward.

---

## Structure

```
growth-space/
  space.manifest.json
  README.md
  LICENSE
  docs/         ← notes, summaries, reading logs, course notes
  ops/          ← habit runbooks, review checklists, learning protocols
  inbox/        ← drop zone: articles, ideas, course links (ignored by git)
  out/          ← finished projects, certificates, published summaries (create as needed)
  .navig/
    space.json  ← canonical manifest
    state/
    plans/
    memory/     ← *.example.json seeds (copy to <name>.json on first use)
    inbox/      ← routes.example.yaml (copy to routes.yaml)
```

---

## Suggested Content

| Folder | Examples |
|--------|---------|
| `docs/` | Book summaries, course notes, skill maps |
| `ops/` | Daily learning habit runbook, habit tracker protocol |
| `inbox/` | Articles to read, courses to evaluate, ideas to explore |
| `out/` | Published writing, finished projects, earned certificates |
| `.navig/memory/` | Long-term context: active skills, learning history |
| `.navig/plans/` | Current learning sprints and habit goals |

---

## Status

**Planned.** This space ships its structure, runbooks, plans and wiki, but no agents,
skills or workflows yet — the roles in `.navig/wiki/agent-guide.md` are a design, not
shipped definitions. For working habit and learning automation today, use `human-space`
(habit-coach, growth-tracker) or `learn-space`.
