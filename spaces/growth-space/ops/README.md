# Personal Growth Ops

Runbooks and protocols for intentional self-development.

---

## Daily Learning Habit

```
[ ] Allocate time block (minimum 20 min)
[ ] Pick one active course/book/skill from .navig/plans/
[ ] Study / practice
[ ] Log progress: one sentence in docs/ or inbox/
```

---

## Habit Tracking Protocol

1. Define the habit in `.navig/plans/` (what, when, why, metric)
2. Log daily: a single line entry (done / skipped / partial)
3. Weekly: review streaks, adjust if consistently skipping
4. Monthly: decide keep / modify / drop

---

## Reading Log Convention

Store in `docs/reading-log.md`:
```
| Title | Author | Started | Finished | Rating | Key Takeaway |
```

---

## Weekly Retrospective

```
[ ] What did I learn this week?
[ ] Which habits held? Which broke?
[ ] What do I want to focus on next week?
[ ] Anything to capture in .navig/memory/?
```
