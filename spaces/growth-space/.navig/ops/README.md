# Growth Space — Ops

## Daily Habit Check-In
1. Log each habit to `#habits`: done / skipped / partial
2. Note: what made it easy or hard today
3. Streak updates automatically

## Weekly Reflection
1. Review habit completion rate for the week
2. Assess progress on active goals
3. Adjust: what to change next week
4. Post to `#reflections`

## Log a Learning Session
1. Post to `#learning`: resource, topic, duration, key takeaway
2. Tag with skill area
3. Skill map updates automatically

## Quarterly Goal Planning
1. Review all active goals — close, extend, or retire
2. Define 1-3 focus goals for next quarter
3. Break into monthly milestones
4. Publish to `#goals`
