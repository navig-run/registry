# Growth Space — Agent Guide

> **Planned roles — not shipped yet.** No agent definitions exist in `.navig/store/agents/`
> for this space; the roles below describe the intended design.

## habit-tracker (Lead)
Manages daily habit check-ins, calculates streaks, and surfaces consistency patterns.

## goal-setter
Maintains goal lifecycle from intention to outcome. Breaks goals into milestones.

## reflection-coach
Facilitates weekly and monthly retrospectives. Extracts patterns and improvement actions.

## skill-tracker
Maintains the skill map and tracks learning activity against each skill area.
