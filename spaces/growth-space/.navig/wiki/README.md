## System Overview

The growth system runs 3 loops:

| Loop | Frequency | Focus |
|------|-----------|-------|
| Habit check-in | Daily | Practice consistency |
| Reflection | Weekly | Course correction |
| Goal review | Monthly | Progress assessment |
| Deep planning | Quarterly | Direction setting |
