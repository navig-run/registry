# Growth Space — Runbooks

## Daily Check-In (5 minutes)

1. Open `#habits` inbox
2. For each habit: done ✅ / skip ❌ / partial 🔄
3. Add one note if anything notable
4. Done

## Weekly Reflection (20 minutes)

1. Review habit completion % for the week
2. Review goal progress
3. Answer: What worked? What didn't? What to change?
4. Set 3 intentions for next week
5. Post to `#reflections`

## Add a New Habit

1. Define clearly: what exactly counts as "done"
2. Add to habit list in memory
3. Start tracking next Monday
4. Review after 4 weeks: keep, modify, or drop
