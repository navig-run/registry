> but no agents, skills or workflows yet. Session recording already exists in core

---

## Purpose

Every Navig session is already recorded by the blackbox. This space surfaces
those recordings publicly — with vault secrets scrubbed — so others can see
real workflows and fork the ones they want. The best sessions trend on the
community feed. Fork count is the engagement metric that matters.

---

## What lives here

- Shared session recordings (vault-scrubbed)
- Published workflow packages
- Trending session archives
- Fork and remix history
