# Open Space — Ops

## Start a Public Session
1. Authorize stream visibility: public
2. Begin session — timeline recording starts automatically
3. Build whatever you're working on
4. End session — timeline artifact published

## Publish a Workflow
1. Complete and test the workflow locally
2. Post to `#workflows` inbox with description
3. Community can install one-click

## Fork a Build
1. Browse community session timelines
2. Click "Fork" on any session
3. Gets installed as your local copy
4. Make it yours
