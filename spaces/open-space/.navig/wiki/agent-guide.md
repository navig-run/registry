# Open Space — Agent Guide

> These roles are the **design target**. No agent files ship with this space yet
> (`.navig/space.json` lists none); see `.navig/GENESIS.md`.

## session-broadcaster
Manages live session streaming, timeline capture, and public/private visibility.

## workflow-publisher
Packages and publishes workflow definitions to the community store.

## fork-manager
Handles fork requests, installs forked builds, and tracks fork lineage.
