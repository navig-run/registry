# Open Space — Runbooks

## Publish a Workflow

1. Complete the workflow locally and test it
2. Export workflow definition (YAML)
3. Add description: what it does, what it needs
4. Post to `#workflows` inbox
5. Community can discover and install it

## Fork a Community Build

1. Find a session timeline you want to fork
2. Click Fork — gets cloned to your instance
3. Customize to your needs
4. Optionally re-publish as a new fork
