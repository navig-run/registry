# GENESIS — Open Space

## Why This Exists

The most powerful NAVIG setups are built by operators learning from each other. Open Space lets you build in public — streaming live sessions, publishing workflows, and letting the community fork what you make.

Without it: every operator reinvents the same solutions in isolation. With it: the best setups become shared infrastructure.

## What It Does

- **Live session streaming** — broadcast your NAVIG session in real-time
- **Workflow publishing** — share workflow definitions others can install one-click
- **Fork + remix** — start from someone else's setup and make it yours
- **Session timeline** — every public session is a forklable artifact

## Origin

Built because the NAVIG community's collective intelligence is its greatest asset. Open builds make everyone better.
