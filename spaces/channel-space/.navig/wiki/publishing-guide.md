# Publishing Guide

## Pre-Upload Checklist

- [ ] Video exported in correct resolution (1080p minimum)
- [ ] Audio levels checked (-14 to -12 LUFS for dialogue)
- [ ] End screen and cards prepared
- [ ] Thumbnail created and scored (target: 7+/10)
- [ ] Title finalised (under 60 characters, keyword-first)
- [ ] Description written (SEO-optimised, timestamps included)
- [ ] Tags prepared (15-30 relevant tags)

## Upload Process

1. **Upload video** — Set to "Private" or "Unlisted" during setup
2. **Add metadata** — Title, description, tags, category
3. **Upload thumbnail** — Custom 1280x720 PNG
4. **Add cards** — Link to related videos at relevant timestamps
5. **Add end screen** — Subscribe + best video + latest video
6. **Set chapters** — Add timestamps in description
7. **Select language** — Primary language + subtitles
8. **Review** — Watch through once, check audio sync
9. **Schedule** — Set publish time for optimal slot
10. **Community post** — Draft a teaser post for subscribers

## Optimal Upload Times

Test with your audience, but general guidelines:

| Day | Best Time (UTC) | Notes |
|-----|-----------------|-------|
| Tuesday | 14:00-16:00 | Strong for tutorials |
| Thursday | 14:00-16:00 | Strong for entertainment |
| Saturday | 10:00-12:00 | Weekend viewing peak |
| Sunday | 10:00-12:00 | Planning/learning content |

## Post-Publish Actions

| Timeframe | Action |
|-----------|--------|
| 0-1 hours | Reply to first comments, share on social |
| 2 hours | Check initial CTR, consider thumbnail swap |
| 24 hours | Review comment sentiment, pin best comment |
| 48 hours | CTR stabilised — evaluate performance |
| 7 days | Full analytics review, extract learnings |

## Format Specifications

| Parameter | Standard | Notes |
|-----------|----------|-------|
| Resolution | 1920x1080 | Minimum; 4K (3840x2160) preferred |
| FPS | 30 or 60 | Match filming framerate |
| Codec | H.264 | Best compatibility |
| Container | MP4 | YouTube preferred format |
| Audio | AAC, 256kbps, 48kHz | Stereo |
| Bitrate | 8-12 Mbps (1080p) | Higher for action content |
