# Growth Subspace

Personal development, learning, habits, and reflection.

## Structure

```
growth/
  habits.csv        ← daily habit tracking log
  learning.csv      ← books, courses, skills log
  retros/           ← weekly retrospective entries (YYYY-WNN.md)
  journal/          ← daily journal entries (YYYY-MM-DD.md)
  books/            ← book notes and summaries
```

## Habits CSV Format

```csv
date,habit,completed,notes
2025-01-01,Morning run,yes,20 min easy pace
2025-01-01,Read 10 pages,yes,Atomic Habits ch.3
```

## Learning CSV Format

```csv
date,type,title,status,notes
2025-01-15,book,Atomic Habits,completed,Excellent framework for habit design
2025-02-01,course,Deep Learning Specialization,in-progress,Coursera — week 3
```

## Owners

- `habit-coach` — habits tracking and design
- `growth-tracker` — learning, books, retrospectives
- `daily-planner` — journal entries and weekly retros
