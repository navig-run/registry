# Singularity Space — Ops

## Ops Procedures

### Weekly Signal Sweep
1. Review `#signals` inbox for the week
2. signal-tracker rates each: significance (1-10), urgency (1-10)
3. oracle synthesizes patterns across multiple signals
4. Archive in `signals/`

### Self-Version Snapshot
1. Run `snapshot-self` skill
2. Record: current beliefs, active goals, skill state, key relationships
3. Compare diff vs previous snapshot
4. Log observations in `memory/self-versions.json`

### Destiny Log Update
1. Review current intentions and trajectory
2. destiny-keeper updates `memory/destiny-log.json`
3. Note any pivots or clarifications

## Formation Quick-Start
- **Weekly**: `signal-watch` for signal sweep
- **Monthly**: `destiny-mapping` for trajectory review
- **Quarterly**: Self-version snapshot + destiny review
