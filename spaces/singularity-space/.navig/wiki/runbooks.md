# Singularity Space — Runbooks

## Weekly Signal Sweep

**Formation:** `signal-watch`  
**Frequency:** Weekly

### Steps
1. Pull all signals logged in `#signals` since last sweep
2. Rate each: significance (1-10), urgency (1-10)
3. Tag by domain: ai / geopolitical / scientific / cultural / personal
4. Synthesize any patterns across 3+ signals
5. Archive in `signals/YYYY/`

---

## Quarterly Self-Version

**Trigger:** Once per quarter

### Steps
1. Run `snapshot-self` skill
2. Record full state snapshot
3. Compute diff vs previous version
4. Rate delta: growth / stasis / regression by dimension
5. Update destiny log with trajectory assessment

---

## AI Frontier Update

**Trigger:** Major AI development or release

### Steps
1. Log event with date, description, and significance
2. ai-researcher assesses: capability delta, timeline implications
3. Update `memory/ai-journal.json`
4. Synthesize implications for destiny log
