# Dev Space — Context

## Purpose

Code authoring, userscript development, and browser extension engineering hub.
A focused workspace for building, debugging, and shipping client-side automation —
Greasemonkey userscripts, Chrome/Firefox Manifest V3 extensions, and general
development utilities.

## Scope

- **Userscripts** — Greasemonkey/Tampermonkey/Violentmonkey userscript authoring,
  metadata blocks, match patterns, and in-browser loading workflows
- **Browser extensions** — Chrome/Firefox Manifest V3 extensions: background service
  workers, content scripts, popup UIs, permissions model, and local load/test cycle
- **General development** — scaffolding, code review, linting, testing automation
