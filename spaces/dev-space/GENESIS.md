# GENESIS — Dev Space

## Why This Exists

Software development is a craft that requires focus. Dev Space is the engineering workshop — a structured environment for writing code, building userscripts, engineering browser extensions, and maintaining development tools.

Without it: context switches kill flow, snippets are lost, and debugging turns into archaeology.

## What It Does

Dev Space is the home for all software engineering work:
- **Code authoring** — IDE-connected development with agent-assisted code review
- **Userscript development** — writing, testing, and publishing browser userscripts
- **Chrome extension engineering** — building, debugging, and packaging extensions
- **Tooling** — scripts, utilities, and developer productivity automation

## Core Agents

| Agent | Role |
|-------|------|
| `coder` | Writes, refactors, and improves code |
| `debugger` | Diagnoses and resolves bugs |
| `reviewer` | Code review and quality checks |
| `scripter` | Builds automation scripts and utilities |

## Primary Formations

- **`dev-workflow`** — Active development mode: write, test, iterate
- **`review-cycle`** — Code review and quality gate
- **`extension-build`** — Build and release cycle for browser extensions

## Origin

Built for developers who need a focused engineering environment that integrates seamlessly with their AI tools — where the context always knows what project is active.
