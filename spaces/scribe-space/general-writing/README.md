# General Writing

Essays, personal writing, reflective pieces, and anything that doesn't fit the other sub-workspaces.

## Getting Started

1. Copy `essay-template.md` into your project file
2. Fill in the opening claim and supporting points
3. Draft freely — no required structure
4. Run `@editor line <file>` for a clarity pass before sharing

## Folder Structure

```
general-writing/
├── essay-template.md          ← Template: argument essay structure
├── <project-name>.md          ← Your writing files
└── README.md
```

## Agents

- `@editor` — any editing pass
- `@storyteller` — narrative non-fiction, personal essays
