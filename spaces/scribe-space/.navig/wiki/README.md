# Scribe Space Wiki

The scribe-space wiki is the living knowledge base for the writers' workspace.
It stores architectural decisions, agent guides, runbooks, and project notes.

## Contents

| File | Purpose |
|------|---------|
| [architecture.md](architecture.md) | Space design decisions and sub-workspace map |
| [agent-guide.md](agent-guide.md) | How to invoke and configure each agent |
| [runbooks.md](runbooks.md) | Operational runbooks for common writing tasks |

## Contributing

Add entries directly to the relevant wiki file. Keep each entry Date | Author | Note format for tracked changes.
