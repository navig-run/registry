# Scribe Space — Context

## Purpose

The ultimate writers' space. A unified hub for all long-form writing domains —
fiction, journalism, screenwriting, technical documentation, content strategy,
and general prose. Every workflow, prompt, and agent is tuned for writers.

## Scope

- **Book writing** — Long-form fiction and non-fiction, chapter management, outlines
- **Journalism** — Investigations, article drafts, interview notes, story briefs
- **Screenwriting** — Feature films and TV scripts in Fountain format
- **Technical writing** — API docs, user guides, SOPs, reference documentation
- **Content strategy** — Editorial calendars, brand voice guidelines, content briefs
- **General writing** — Essays, copy, miscellaneous prose

## Active Agents

storyteller · journalist · editor · content-strategist · screenwriter · tech-writer
