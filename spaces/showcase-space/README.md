# Agent Showroom

> Browse, demo, and install community agents — the App Store for Navig personas.

**Tier:** community · **Status:** planned  
**Owner:** navig-run · **Created:** 2026-03-17

---

## Purpose

Agent personas are the most personal thing in a Navig instance — and the most
shareable. The showroom is a gallery where community-published agents can be
previewed, one-click installed, and run immediately. No setup, no config: install
a stranger's agent and it's running in your instance in 10 seconds.

---

## What lives here

- Curated agent persona listings
- Install logs and active agent roster
- Review and rating notes
- Featured / trending agent archives
