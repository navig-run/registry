## Asset Types

| Type | Description |
|------|-------------|
| `agent` | AI agent with defined role and capabilities |
| `pack` | Bundled set of tools and skills |
| `formation` | Multi-agent coordination pattern |
| `workflow` | Step-by-step automation sequence |
| `persona` | Agent identity and reasoning style |
| `space` | Complete space with agents, formations, and data structure |

## Quality Requirements

All community assets must have:
- Valid manifest with version and description
- README explaining purpose and usage
- No hardcoded credentials or paths
