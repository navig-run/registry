# Showcase Space — Runbooks

## Submit to Gallery

1. Verify asset has: manifest, README, tests
2. Run asset quality check
3. Post to `#submissions` with description
4. Gallery curator reviews within 48h
5. If approved: published to community gallery
6. Asset receives a gallery ID and install URL

## Install a Community Asset

1. Browse gallery or search for asset type
2. Preview README and ratings
3. Click install
4. Asset installed in your NAVIG instance in <10 seconds
5. Rate it after using
