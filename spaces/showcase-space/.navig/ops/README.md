# Showcase Space — Ops

## Submit an Asset
1. Prepare asset: valid manifest, README, tests passing
2. Post to `#submissions` inbox
3. Community review (automated + human)
4. Publish to gallery

## Feature Curation
1. Weekly review of `#submissions`
2. Curator agent rates: quality, novelty, usefulness
3. Top assets promoted to `#featured`

## Report a Problem
1. Rate an asset poorly with a note
2. Flag for curator review if critical issue
3. Asset can be delisted if serious concerns confirmed
