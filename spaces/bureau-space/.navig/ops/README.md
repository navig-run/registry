# Bureau Space — Ops

## Add a Document
1. Drop the letter / PDF / scan in `inbox/`
2. `navig paperwork scan inbox --space bureau-space --profile personal` → a reviewable plan
3. `navig paperwork apply --yes --space bureau-space` — letters are filed by organism, deduped, undo-able
4. `navig paperwork handoff --yes --space bureau-space` — identity and health documents are
   encrypted into `navig cabinet` (the document vault), never kept as plain files here
5. Deadlines: `navig paperwork echeances --space bureau-space`

## Track a Dossier
1. Create dossier record: name, category, start date, required documents
2. Log each step as it progresses
3. Update status: en-cours → en-attente → cloture
4. Archive when resolved

## Deadline Alert Response
1. Check `#deadlines` for upcoming obligations
2. Gather required documents
3. Complete the administrative action
4. Mark deadline as done, archive receipt

## Annual Tax Prep (Impôts)
1. April: gather all income documents (avis d'imposition, bulletins de salaire)
2. Review pre-filled declaration online
3. Add missing income / deductions
4. Submit before deadline (usually May)
5. File confirmation receipt
