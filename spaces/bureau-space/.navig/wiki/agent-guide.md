# Bureau Space — Agent Guide

> **Planned roles — not shipped yet.** No agent definitions exist in `.navig/store/agents/`
> for this space. Until they do, the working tools are `navig paperwork` (scan → review →
> apply → handoff) and `navig cabinet` (encrypted document vault) — see `../ops/README.md`.

## document-archivist (Lead)
Manages document filing and retrieval. Letters go through `navig paperwork` (scan → review →
apply); identity and health documents live encrypted in `navig cabinet` (search, export,
expiring). Suggests categories for new documents.

## deadline-guardian
Tracks all administrative deadlines. Sends alerts 30 days and 7 days before each deadline.

## dossier-tracker
Manages active administrative processes from creation to resolution.

## correspondence-manager
Logs and tracks official correspondence — letters sent, responses received, reference numbers tracked.
