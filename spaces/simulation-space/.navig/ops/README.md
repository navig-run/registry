# Simulation Space — Ops

## Ops Procedures

### Run a Debug Loop
1. Identify the target behavior/failure
2. Activate `debug-loop` formation
3. Trace the failure to root cause
4. Propose and log a fix/experiment
5. Schedule a follow-up check

### Log a Habit Run
1. Record habit in `#habits` inbox
2. habit-engine updates streak and pattern data
3. Weekly: review habit trends in simulation review

### Run an Experiment
1. Define hypothesis in `experiments/`
2. Set duration and metrics
3. Run and log results daily
4. Review outcomes and update agent model

## Formation Quick-Start
- **Daily**: Log habits via `#habits` inbox
- **Weekly**: `habit-sim` formation review
- **Monthly**: Full `agent-lab` formation
