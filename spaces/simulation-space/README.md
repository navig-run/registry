# Simulation Space

> The self as a system. Debug it. Simulate it. Model it.

## Agents

| Agent | Role |
|-------|------|
| `debugger` | Root-cause analysis on behavioral failures — symptom → trace → hypothesis → retest |
| `habit-engine` | Habit tracking, streaks, failure patterns |
| `agent-modeler` | Predictive behavioral models of people in your environment |
| `probability-analyst` | Probability assessments, Bayesian belief tracking, forecast scoring |

## Skills

| Skill | Purpose |
|-------|---------|
| `run-habit` | Log a habit run (completed / missed / partial) + streak computation |
| `log-debug` | Open a debug ticket with symptom, trace, hypothesis, retest date |
| `update-agent` | Create or update an agent behavioral model with observations + predictions |
| `assess-probability` | Log a probabilistic claim with confidence and resolution date |

## Formations

| Formation | Purpose |
|-----------|---------|
| `debug-loop` | Default — behavioral debugging + probability analysis |
| `habit-sim` | Habit tracking and failure analysis |
| `agent-lab` | External agent modeling |
