# Space: homelab

## Purpose
Unified command-and-control hub spanning ALL personal hardware, devices, networks, and
computers — Windows, Linux, and macOS. This space gives a single operator full situational
awareness and automation authority over every machine they own or manage.

## Scope
- Physical hosts: homelabs, servers, NAS, SBCs (Raspberry Pi / Jetson)
- Network: routers, switches, APs, VLANs, VPNs
- Peripherals: storage arrays, KVM switches, UPS units
- Operating systems: Windows 10/11, Ubuntu/Debian/Arch Linux, macOS 13+
- Remote access: SSH, WOL, RDP, VNC

## Active Agents
atlas · sentinel · wrench · herald · archivist · pulse

## Active Formations
network-ops · hardware-patrol · cross-platform-ops · security-watch · maintenance-crew

## Key Paths
- Space root:      the folder containing this .navig/ (installed: ~/.navig/spaces/homelab-space)
- Config:          .navig/config.yaml
- Device registry: .navig/memory/device-registry.json (copy from device-registry.example.json)
- Wiki:            .navig/wiki/
